# KEA — Prototipe website

Pratinjau desain KADIN Export Academy untuk review klien.

**Buka website:** https://hrenanda.github.io/kea/

Seluruh gambar, logo, aksen banner, dan font Montserrat tertanam di `index.html`, sehingga prototipe dapat dibuka tanpa aset eksternal.

Ini prototipe UI. Form kontak, login admin, CMS, dan database belum aktif. Konten target dan roadmap mengikuti label status dokumen sumber. Foto tematik adalah ilustrasi, bukan dokumentasi kegiatan KEA.

Sumber foto banner: `banner-photo-sources.json`. Lisensi Montserrat: `OFL-Montserrat.txt`.
